Dies ist euer Git-Repository, um eure Hausaufgabenlösungen hochzuladen! 

# Ordnerstruktur
Bitte behaltet die Ordnerstruktur ein:Die Pflichtaufgabe A des Blattes B kommt in den Ordner blattB/pflichtaufgabeA. Die Abgaben zu Aufgabe 1 des Blattes 2 kommen also in den Ordner blatt2/pflichtaufgabe1/

Für manche Aufgaben existiert ein solcher Unterordner bereits. Fehlen welche, dürfen sie hinzugefügt werden.

# Main-Files
Für Programmieraufgaben existiert bereits ein Ordner mit einer Main.java. Diese darf (und soll auch) bearbeitet werden, aber nicht gelöscht werden. Sobald in einem der Unterordner Code angepasst wird, werden dazugehörige Main.java Dateien nach Hochladen überprüft, ob diese kompilieren.

# gitlab_ci.yaml
Die .yaml-Datei darf nicht geändert werden, es sei denn man ist explizit im Hausaufgabenblatt dazu aufgefordert.

# Erlaubte Dateien
Sofern nicht anders auf dem Hausaufgabenblatt erwähnt, dürfen nur .txt, .md, .pdf (für T-Aufgaben), und .java Dateien (für P-Aufgaben) hochgeladen werden. Sehen wir .class-Dateien oder Dateien von IDEs (z.B. Eclipse, Visual Studio) kann dies zu Punktabzug führen.
